# Academy — учёт учебного заведения на Blazor

Веб-приложение для учёта академии: направления обучения, группы, студенты, преподаватели и дисциплины.

**Стек:** C# · .NET 8 · Blazor · Entity Framework Core · MS SQL Server · Bootstrap

## Что умеет

- **Направления, группы, студенты, преподаватели, дисциплины:** просмотр списков, карточки с подробностями, добавление и редактирование
- **Группы:** выбор направления из выпадающего списка, учебные дни отмечаются галочками и показываются словами (Пн., Ср., Пт.), фильтр по направлению
- **Студенты:** вместо id показываются название группы и направление, фильтры по направлению и группе
- **Связи многие-ко-многим:**
  - у дисциплины виден список преподавателей, которые могут её вести
  - у преподавателя виден список дисциплин, которые он может вести

## Модель данных

`Direction` → `Group` → `Student` (один-ко-многим)
`Teacher` ↔ `Discipline` (многие-ко-многим через `TeacherDisciplineRelation`)
`Discipline` ↔ `Direction` (многие-ко-многим через `DisciplineDirectionRelation`)

Связанные данные подгружаются через `Include()` в EF Core.

## Структура

```
Models/            сущности БД
Data/              AcademyContext (EF Core)
Components/Pages/  страницы Blazor: списки, карточки, формы редактирования
Components/Layout/ меню и общий шаблон
```

## Запуск

Нужны .NET 8 SDK и SQL Server Express.

1. Создать базу `PD_321` в SQL Server. В таблице `Groups` должны быть поля учебных дней: `monday` … `sunday`
2. Проверить строку подключения в `appsettings.json`:
   `Server=.\SQLEXPRESS;Database=PD_321;Trusted_Connection=True;TrustServerCertificate=True;`
3. Запустить: `dotnet run`

Учебный проект, выполнен в рамках обучения в Академии ТОП.
